# Indie Owls Creative Studio

SaaS product design and development agency website, built with [Gatsby](https://www.gatsbyjs.com/).

## Tech stack

- **Framework:** Gatsby 5, React 18
- **Styling:** styled-components 6, normalize.css
- **Deployment:** Netlify
- **Testing:** Jest, Testing Library

## Prerequisites

Node.js 19.4.0 (see `.nvmrc`).

## Getting started

```bash
npm install
npm run dev
```

The dev server runs at **http://localhost:8000**.

## Scripts

| Command         | Description                    |
| --------------- | ------------------------------ |
| `npm run dev`   | Start development server       |
| `npm run build` | Production build to `public/`  |
| `npm run serve` | Serve production build locally |
| `npm test`      | Run Jest test suite            |
